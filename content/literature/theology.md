# 各种哲学与信仰体系的基本公理

## 易卜拉欣一神教（伊斯兰教，犹太教，基督教）

三教共享
- 认主独一：存在唯一的、全知全能的造物主（真主 / 上帝），祂是一切存在的终极根源与维持者，无始无终，无与伦比，独一无偶。
- 两世说：存在今世（此生）与后世（来世）的二元时间结构。今世为考验之所，后世为最终清算与永恒归宿（乐园 / 火狱）之所。末日审判时，所有人将按其信仰与行为被裁决。
  + 犹太教更侧重于今世的律法实践与社群伦理，两世说的地位相对更弱：法利赛人和后来的拉比犹太教接受复活与后世，撒都该人否认复活，而部分卡巴拉神秘主义分支甚至相信灵魂转世。
- 天启经典：造物主通过降示经典向人类传达旨意与引导，这些经典（古兰经、托拉等）的内容在其原初状态下具有神圣权威性。
- 先知制度：造物主拣选特定的人类作为先知 / 使者，作为神与人之间的信息传递中介。先知受神拣选以传达启示，其谱系构成一条从阿丹（或穆萨）至各传统终点的连续链条。

伊斯兰教
- 封印先知：穆罕默德是先知谱系的最后一位，此后不再有新的先知或新的天启经典降世。《古兰经》作为最终启示，是对此前一切经典的确证与守护，其文本受神保护免于篡改。
- 前定：真主对万物的过去、现在和未来有全知的预见，并将其记录在天牌上。宇宙间发生的一切皆由真主的意欲与定度所决定。但这并不否定人的自由意志：人类拥有选择善恶的相对自由，因此须在末日审判中为自己的选择承担责任。

犹太教
- 神之选民：上帝与以色列民族（亚伯拉罕、以撒、雅各的后裔）立下特殊盟约，赋予其独特的律法义务与使命。“拣选”核心含义为责任与义务，而非优越性。
- 口传律法：拉比犹太教认为上帝在西奈山向摩西降示书面律法（即《托拉》文本）的同时，也传授了作为其解释与详细指导的口传律法。这些律法历经历代先知与拉比口耳相传，最终编纂汇集成《密释纳》与《塔木德》等文献，是理解和实践书面律法不可或缺的权威。

基督教
- 原罪理论：
  + 奥古斯丁诠释：亚当和夏娃的悖逆使得罪的本性与灵性的死亡遗传至全人类。人凭自身力量无法修复这一与神之间的根本断裂，因此需要神主动施行救赎。
  + 加尔文诠释：原罪并非一桩具体的罪行，而是指人因始祖堕落而丧失了原初恩典的状态。人在此状态下“全然败坏”并非指人所做的每一件事都尽其所能地邪恶，而是指人的每一项官能都已被罪所玷污，以至于人完全无力凭自身意志转向神或做出真正的善。
  + 东正教诠释（祖罪）：人类从始祖继承的并非罪责本身，而是死亡与败坏的后果。人的本性因堕落而受到创伤与遮蔽，倾向于犯罪，但并不承担亚当个人行为的罪咎。救赎的核心是“神化”——人性借基督的道成肉身与复活被重新恢复并提升，参与神的生命。
- 三位一体：独一的上帝存在于三个平等的位格（圣父、圣子、圣灵）之中，三者同质、同权、同荣。神是不可分割的独一实体，但以三个位格的方式永恒存在并参与创造与救赎。
- 道成肉身：神的道 / 圣子取了完全的人性，在拿撒勒人耶稣身上实现了神人二性的联合（一个位格，完全的神性与完全的人性）。耶稣通过其受难、死亡与复活完成了对人类罪的救赎，开启了救恩之路。

## 佛教

佛教共同基础
- 因缘和合：一切现象皆由因缘条件和合而生，任何事物都不具有独立自存的实体（无自性 / 无我）。十二因缘揭示了从无明到老死的轮回生起机制。此公理同时否定了造物主创世与事物偶然无因生起这两种见解。
- 轮回说：有情众生在六道（天、人、阿修罗、畜生、饿鬼、地狱）中依业力不断流转受生，此过程无始以来持续运作。轮回本质为苦（dukkha，即不完满），其驱动力为无明与贪爱。
- 涅槃：贪、嗔、痴三毒的彻底止息，轮回的终结，是修行的最终目标。涅槃不是断灭，也不是某种永恒存在的“天堂”，而是对苦因的根本断除，是不可以有无等概念范畴完全描述的解脱境界。
- 三法印 / 四法印：
  + 诸行无常（一切有为法皆在刹那生灭变化）；
  + 诸法无我（一切现象皆无独立、常在的实体）；
  + 涅槃寂静（彻底平息烦恼后的终极解脱境界）；
  + 有漏皆苦（凡与无明烦恼相应、带有染污与执着的一切有为法，其本质皆是苦）。
- 四圣谛：
  + 苦谛：轮回存在的本质是苦（包含苦苦、坏苦、行苦），即不完满；
  + 集谛：苦的根源是无明所驱动的贪爱与执取；
  + 灭谛：苦的止息（即涅槃）是可实现的；
  + 道谛：通往灭苦的方法是八正道（正见、正思维、正语、正业、正命、正精进、正念、正定）。

大乘佛教
- 般若波罗蜜多：超越二元分别的究竟智慧，直观照见一切法的空性——即一切现象无自性、无独立实体。般若不是知识的积累或概念的理解，而是对实相的直接证悟，是到达彼岸（波罗蜜多）的核心。
- 法即非法（非法非非法）：佛所说的一切法本身亦是因缘施设，为应机度众生之方便，不可执为实有。如《金刚经》所喻“筏喻”——法如渡河之筏，到岸则应舍；若执着于法本身，则法亦成障碍。说法者无法可说，是名说法。
- 无住涅槃：大乘佛教对涅槃概念的根本重构。菩萨以般若故不住生死（不为烦恼业力所缚），以大悲故不住涅槃（不舍弃众生趣入寂灭独自解脱）。既不沉溺轮回，亦不安住寂灭，而是于生死中自在度众而无所住。
- 菩提心：为利益一切众生而发愿成就无上佛果，这是大乘区别于声闻乘的核心发心。

## 道家学说与道教

基础道家学说：
- 道法自然：道是天地万物的终极根源与运行法则，无形无象、无名无状，先天地而生，独立而不改，周行而不殆。“自然”不是指自然界，而是“自己如此”——道不效法任何外在之物，其运作方式即是自本自根、本然如是。万物各循其性即是合道。
- 无为而治：不以人为造作、机心巧智去强行干预事物的自然进程。圣人治世如“治大国若烹小鲜”，顺物之性，因势利导，不妄为、不强为，使万物自化自正。其自然的政治推论：最好的治理是百姓不知有治者存在。
- 得鱼忘筌：语言、概念、名相皆为指向道的工具，而非道本身。“道可道，非常道”，道不可以言语穷尽，凡有所言说皆为方便施设。得意则当忘言，执着于文字名相则反失其真。

道教宗教神学：
- 道气化生：道生一，一生二，二生三，三生万物。宇宙万物由道化生元气，元气分判为阴阳，阴阳交感化生万物。此为道教的宇宙生成论，以“气”为基本存在论范畴，一切有形无形之物皆为气之聚散变化。道教否认人格化造物主的“从无创有”，而主张万物皆从道之自然流衍中化生。
- 道体遍在：道不是超越于世界之外的他者，而是内在于万物之中的本源。每一存在物皆禀道而生、含道而在。人身即为道之具现，修行即是复归自身本有之道性。
- 因果报应：人的善恶行为会产生报应，不仅及于自身，更可累积承传于子孙后代（承者受先人之过，负者为后世造因）。天道好还，善恶有报，形成道教独特的伦理因果律。此说兼有个人与家族两个维度，与佛教侧重个人业力轮回不同。
- 仙道贵生：与佛教以解脱轮回为终极目标不同，道教重视肉身存在的价值，以长生久视、得道成仙为修行目标。形神俱妙、与道合真的“仙”是人通过修炼精气神而实现的生命超越状态。死亡并非不可克服的必然，而是可以通过修行超越的。
- 三清（道的位格化）：道之终极实在被象征性地表达为三清——玉清元始天尊、上清灵宝天尊、太清道德天尊。三清原则上并非三个独立的神，而是道在不同层面和宇宙阶段的显化与人格化表达。元始天尊象征道之未始、太初之先；灵宝天尊象征道之布化、经教流传；道德天尊象征道之在世教化（常与老聃关联）。

## 琐罗亚斯德教（拜火教）

- 善恶之战：存在两个根本对立的灵性力量——阿胡拉·马兹达（智慧之主，至善、秩序与光明的本源）与安格拉·曼纽（恶之灵，谎言、混乱与黑暗的本源）。二者之间的斗争构成宇宙历史的核心戏剧。
  + 祖梵派主张时间之神祖梵为更高本源，善恶二灵皆为其子，属一元论框架下的二元论；
  + 正统马兹达崇拜则主张阿胡拉·马兹达为至高唯一的神，安格拉·曼纽并非与其同等的本源性存在，而是对立的选择/灵性，属修正二元论或伦理一元论。
- 阿莎与德鲁杰：阿莎即真理、正义、宇宙秩序的法则；德鲁杰即谎言、欺诈、混乱。一切存在和行为都参与在这一对立之中。人的道德选择本质上是在阿莎与德鲁杰之间的抉择。
- 自由意志与抉择：人被赋予自由意志，必须在善与恶之间主动做出选择。这一选择具有宇宙性意义——每个人的善念、善言、善行都是在协助阿胡拉·马兹达对抗恶的力量；每一恶行则壮大了安格拉·曼纽的势力。人不是被动的受造物，而是善恶宇宙之战中的积极参与者和战士。
- 末世更新：在时间尽头，善将彻底战胜恶，安格拉·曼纽被永久消灭或无力化，死者复活，世界经熔化金属之河的净化后恢复为完美的原初状态。早期伽萨文本的末世论相对模糊和诗意化，而后期教义倾向于认为所有灵魂（包括在地狱中受罚者）最终都将被净化并进入更新后的完美世界，恶不具有永恒性。
- 善的创造：物质世界是阿胡拉·马兹达的善的创造，本质上是好的。身体与物质世界是灵性的战场也是灵性的盟友。因此拜火教反对禁欲主义和遁世修行，肯定婚姻、农耕、畜牧、繁衍等积极参与物质世界的行为为宗教义务。使大地肥沃、使荒漠开花本身即是神圣行为。
- 火与光的神圣性：阿塔尔（火）是阿胡拉·马兹达之子或马兹达的显现，是阿莎在物质世界中最直接的可见象征——代表真理、正义与神圣智慧之光。火不是被崇拜的偶像，而是祈祷时面对的方向和神圣秩序的活的象征（类似于礼拜的朝向）。保持火的洁净与不灭是维护宇宙秩序的仪式性参与。

## 灵知论（Gnosticism，诺斯替主义）

- 巨匠（德谬哥 / Demiurgos）造物：可见的物质世界并非由至高神性直接创造，而是由一个低级的、无知的或恶意的巨匠造物主所造。巨匠或因无知而自以为是唯一的神，或因傲慢而囚禁灵性火花于物质牢笼之中。物质世界本质上是缺陷的、囚禁性的，而非善的创造。巨匠常被指向希伯来圣经中的造物神，从而构成对易卜拉欣创世叙事的系统性颠覆。
- 灵性领域（普累若麻 / Pleroma）：在物质世界之上（或之前）存在一个圆满的、纯粹的灵性领域，至高的不可知之神居于其中，并流溢出一系列成对的神圣存在（永世 / Aeons）。灵性领域是灵魂的真正家乡，物质世界则是对它的拙劣模仿或堕落副产品。人内在的灵性火花本属于灵性领域，却因宇宙性事故或巨匠的囚禁而沉沦于物质之中，遗忘了自身的神圣本源。
- 流溢：神性通过逐层流溢产生出层层存在，如光从光源逐级递减，每一层流溢都比上一层更远离神性本源、更稀薄、更缺乏。巨匠及物质世界处于流溢链条的最末端或断裂处，是神性光辉几近耗竭之所。此模型意味着存在一条从至高到至低的连续性等级，而最底层已经退化到近乎与本源对立的程度。
- 灵知救赎：救赎不通过信仰、律法或仪式实现，而是通过灵知——即对自身真实本源的直接认知与觉醒——实现。当灵魂认出自身内在的神性火花、识破物质世界的幻象本质与巨匠的虚假权威时，便从物质的囚禁中解放，上升穿越诸天层级，最终归返灵性领域。

## 黑格尔唯心辩证法

- 绝对唯心论：一切存在的终极实在是“绝对精神”，它是通过世界的全部展开来实现自身的、能动的理性整体。自然、历史、人类意识皆为绝对精神自我认识之环节。“凡是合乎理性的都是现实的，凡是现实的都是合乎理性的。”
- 实体即主体：真正的实在不是静止的、惰性的“实体”，而是自我运动、自我分化、自我回归的“主体”。绝对精神是活的过程，不是凝固的结果。真理不是现成的东西，而是自身生成自身的全过程。
- 精神的自我外化与回归：绝对精神通过将自身外化为自然界和有限精神（即“异化为他者”），再通过人类的意识、社会、宗教与哲学活动来扬弃这一异化，最终达到对自身的完全认识和回归。世界历史就是绝对精神从“自在”（潜在的、未展开的）经过“自为”（在对立中意识到自身）而达到“自在且自为”（完全实现的自我知识）的过程。
- 辩证运动：一切事物通过内在矛盾而自我发展，其基本结构为肯定—否定—否定之否定。矛盾不是应当消除的逻辑错误，而是一切运动与生命力的内在根源。每一个范畴或存在阶段都在自身中包含着否定自身的因素，并由此过渡到更高的统一。
- 扬弃（Aufhebung）：辩证运动中的否定不是单纯的取消或毁灭，它同时具有三重含义——否定、保存、提升。低级阶段在被超越的同时，其合理内容被保留并整合到更高的统一之中。历史不是对过去的简单抛弃，而是不断的积累性超越。
- 历史的目的论：世界历史不是偶然事件的堆积，而是精神实现自由的合目的过程。“世界历史就是自由意识的进步。”每一历史阶段都代表精神对自由的更高程度的觉悟。“理性的狡计”（List der Vernunft）意味着个人的激情与利益在不自觉中被历史理性所利用，以实现超出个人意图的更宏大目标。
